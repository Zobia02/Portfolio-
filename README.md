# Syeda Zobia Irshad — Portfolio

A bilingual portfolio for Syeda Zobia Irshad, an AI master's student and software engineer working across applied AI, RAG, cloud services, and modern web development.

The site is available in English and German and is built with Next.js, React, TypeScript, and custom responsive CSS.

## Highlights

- English / German language switcher
- Responsive single-page portfolio layout
- About, education, experience, selected work, skills, and contact sections
- ServiceSwift RAG customer support assistant case study
- Downloadable CV and direct email / LinkedIn links
- Designed for deployment on Vercel

## Tech stack

- Next.js 15
- React 19
- TypeScript
- CSS with responsive layout and custom visual system
- Google Fonts: Manrope and DM Mono

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
npm run start
```

## Deployment

This project is configured as a standard Next.js app and can be deployed directly to Vercel. Import the GitHub repository, keep the default build settings, and deploy.
